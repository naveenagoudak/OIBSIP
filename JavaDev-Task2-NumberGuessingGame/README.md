# Number Guessing Game (Java)

A console-based Number Guessing Game built using Java for the Oasis Infobyte Internship (OIBSIP).

## Features
- Generates a random number between 1 and 100.
- Maximum of 7 attempts allowed per round.
- Provides directional hints ("Too High!" or "Too Low!").
- Supports multiple rounds with a score tracking system.
- Input validation to handle invalid inputs gracefully.

## Tech Stack
- Java (JDK 8+)
- Standard libraries: `java.util.Scanner`, `java.util.Random`

## How to Run
1. Compile the code:
   `javac NumberGuessingGame.java`
2. Run the application:
   `java NumberGuessingGame`
